# NUVORA TV — prototipo inicial

Aplicación Android de prueba para reproducir canales en vivo a partir de credenciales Xtream Codes que el usuario ya tenga autorizadas.

## Incluye
- Pantalla de acceso con URL, usuario y contraseña.
- Consulta de `get_live_streams`.
- Lista plana de canales en vivo.
- Reproducción con AndroidX Media3 / ExoPlayer.

## Importante
Este proyecto es un punto de partida, no una versión terminada ni verificada en Fire TV. El formato de URL de reproducción puede variar según el proveedor. Las credenciales todavía no están implementadas con almacenamiento cifrado; no distribuir públicamente esta versión. Úsalo únicamente con servicios y enlaces que tengas autorización para utilizar.

## Compilar
Abrir el proyecto con Android Studio y compilar la variante `debug`.
